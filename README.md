# Phone Deck

**아이폰을 스트림덱처럼 쓰는 Wi-Fi 리모컨입니다.** 아이폰 홈 화면의 버튼과 다이얼로 PC의 프로그램 실행, 단축키, 글자 입력, 볼륨, 프리미어 색보정까지 조작합니다.

```
[아이폰 홈 화면 앱] ──같은 Wi-Fi──▶ [PC의 Phone Deck] ──▶ 단축키 · 글자 입력 · 앱 실행 · 볼륨 · 프리미어
```

- 아이폰에는 **아무것도 설치하지 않습니다.** 사파리로 열고 홈 화면에 추가하면 앱처럼 실행됩니다.
- PC에는 **Node.js**만 있으면 됩니다. 다른 라이브러리는 필요 없습니다.
- 버튼과 다이얼은 아이폰과 PC의 **편집 화면**에서 직접 바꿀 수 있습니다.

> 스트림덱 같은 컨트롤러를 아이폰으로 대신해 보려고 만든 개인 프로젝트입니다. Elgato, Loupedeck, Adobe와는 관련이 없습니다.

## 주요 기능

- **버튼:** 앱·웹사이트·폴더 열기, 단축키, 글자 입력(한글·이모지), 여러 동작 차례로 실행, 페이지 이동
- **다이얼:** 손가락으로 돌리는 다이얼. PC 볼륨(1% 단위), 타임라인 조그(1프레임씩), 마우스 휠, 마우스로 값 끌기
- **프리미어 색보정 다이얼:** Lumetri Color의 Exposure·Contrast·Highlights·Shadows·Whites·Blacks·Temperature·Saturation을 0.1씩 조절 (프리미어 확장 설치 필요)
- **프로그램별 자동 페이지 전환:** 예를 들어 프리미어가 앞에 오면 편집용 페이지로 자동으로 바뀝니다
- **편집 화면:** 아이폰에서는 이름·아이콘·색·위치, PC에서는 동작까지 편집
- **실제 앱 아이콘 자동 표시**, 아이콘 1,700여 개(한글 검색), 사진첩 이미지 사용
- **고정 주소 `phonedeck.local`:** Wi-Fi를 바꿔도 홈 화면 아이콘이 그대로 연결됩니다
- **PC 켤 때 자동 실행**, 아이폰 하나로 **여러 컴퓨터** 번갈아 조작

## 필요한 것

- Windows 10 또는 11 PC
- [Node.js](https://nodejs.org) 18 이상
- 아이폰 (PC와 **같은 Wi-Fi**에 연결)
- (선택) 프리미어 색보정 다이얼을 쓰려면 Adobe Premiere Pro

## 설치와 시작 (Windows)

1. 이 저장소를 내려받습니다. GitHub에서 **Code → Download ZIP** 후 압축을 풀면 됩니다.
2. [nodejs.org](https://nodejs.org)에서 Node.js(LTS)를 설치합니다.
3. 폴더 안의 **`start.bat`**을 더블클릭합니다.
   - 처음 실행하면 기본 설정 파일 `config.json`이 자동으로 만들어집니다.
   - **Windows 방화벽 창**이 뜨면 **허용**을 누르세요. 아이폰이 PC에 접속하려면 필요합니다.
4. 잠시 후 PC 브라우저에 **QR 코드**가 뜹니다. 아이폰 카메라로 찍으세요.
5. 사파리에서 **공유 → 홈 화면에 추가**를 누르면 끝입니다. 이제 홈 화면 아이콘으로 실행됩니다.

### 접속 주소와 접속 코드

- QR 주소는 `http://phonedeck.local:8765/?t=접속코드` 형태입니다. PC가 `phonedeck.local`이라는 이름을 네트워크에 알리기 때문에, PC의 IP 주소가 바뀌어도 그대로 연결됩니다.
- 이 이름이 통하지 않는 네트워크(일부 회사·공용 Wi-Fi)에서는 QR 페이지 목록에서 IP 주소를 고르세요.
- 주소 끝의 **접속 코드**는 PC마다 무작위로 만들어집니다. 같은 Wi-Fi의 다른 사람은 이 코드 없이 PC를 조작할 수 없습니다. 코드를 바꾸려면 `.token` 파일을 지우고 다시 실행하세요.
- QR 페이지는 언제든 PC에서 `http://localhost:8765/setup`으로 다시 열 수 있습니다.

### 켜기 · 끄기 · 자동 실행

| 파일 | 하는 일 |
|---|---|
| `start.bat` | Phone Deck을 켭니다. 이미 켜져 있으면 QR 페이지만 엽니다 |
| `stop.bat` | Phone Deck을 끕니다 |
| `autostart-on.bat` | PC에 로그인하면 **창 없이** 자동으로 켜지게 합니다 |
| `autostart-off.bat` | 자동 실행을 끕니다 |

자동 실행 중에 나오는 기록은 `deck.log`에 남습니다. **새 버전으로 업데이트했다면 `stop.bat` → `start.bat` 순서로 다시 켜세요.** `start.bat`만 다시 누르면 예전 버전이 계속 실행됩니다.

## 버튼 편집하기

설정 파일을 직접 고치지 않아도 됩니다. 편집 화면에서 저장하면 아이폰에 바로 반영됩니다.

### 아이폰: 겉모습과 위치
위쪽 **연필 버튼**을 누르면 편집 모드가 됩니다.
- **버튼을 탭:** 이름, 테두리 색, 아이콘을 바꿉니다. 아이콘은 "가위", "볼륨"처럼 한글로 검색하거나, 이모지, **사진첩 이미지**, 앱의 실제 아이콘을 고를 수 있습니다.
- **버튼을 끌어서 다른 칸에 놓기:** 두 칸의 자리를 바꿉니다.

### PC: 동작까지 — `http://localhost:8765/edit`
- **빈칸(＋)을 클릭하면 새 버튼**이 생깁니다. 버튼은 끌어서 자리를 바꿉니다.
- 버튼마다 **누르면 할 동작**을 정합니다. 단축키는 **녹화** 버튼을 누른 뒤 키를 누르면 입력되고, 프로그램은 **설치된 앱에서 고르기**로 고릅니다.
- **시험 실행**으로 저장 전에 동작을 확인할 수 있습니다.
- 다이얼 만들기, 페이지 추가·삭제·순서 변경, 열 수 같은 전체 설정도 여기서 합니다.
- **저장**(또는 Ctrl+S)하면 직전 상태가 `config.backup.json`으로 백업됩니다.

PC 편집 화면은 **그 PC에서만** 열립니다. 버튼 동작에는 명령 실행도 있어서, 다른 기기가 동작을 바꾸지 못하게 막아 두었습니다. 아이폰 편집은 겉모습과 위치만 바꿀 수 있습니다.

## 프리미어 색보정 다이얼

**색보정** 페이지의 다이얼 8개는 프리미어 **Lumetri Color**의 기본 보정 값을 직접 바꿉니다.

- 정밀 모드는 1칸에 **0.1**, 빠르게 모드는 1칸에 1.0씩 바뀝니다. 다이얼마다 PC 편집 화면에서 바꿀 수 있습니다.
- 다이얼 가운데에 **현재 값**이 표시되고, 가운데를 탭하면 **기본값**(Saturation 100, 나머지 0)으로 돌아갑니다.
- 조절 대상은 **선택한 클립**입니다. 선택한 클립이 없으면 재생 헤드 아래 맨 위 클립이 바뀝니다.
- 클립에 **Lumetri Color 효과가 한 번은 들어가 있어야** 합니다.
- 돌릴 때마다 프리미어의 실행 취소 기록이 하나씩 쌓입니다.

### 프리미어 확장 설치 (처음 한 번)

1. **프리미어에서 서명 없는 확장을 허용**합니다. 이 확장은 Adobe 서명을 받지 않은 개인 확장이라 필요합니다.
   - 레지스트리 편집기에서 `HKEY_CURRENT_USER\Software\Adobe\CSXS.12`(프리미어 버전에 따라 `CSXS.11`)를 열고, 문자열 값 `PlayerDebugMode`를 만들어 `1`로 설정합니다.
   - 이 설정은 Adobe 프로그램이 서명 없는 확장도 불러오게 하는 개발자 설정입니다. 믿을 수 있는 확장만 설치하세요.
2. `install-premiere-bridge.bat`을 실행합니다. 확장이 `%APPDATA%\Adobe\CEP\extensions\PhoneDeckBridge`에 복사됩니다.
3. **프리미어를 껐다가 다시 켭니다.** 켜질 때 Phone Deck Bridge가 자동으로 연결됩니다.
4. 연결 상태는 프리미어 메뉴 **창 → 확장 → Phone Deck**에서 볼 수 있습니다.

프리미어 2026(26.x)에서 확인했습니다. 프리미어의 표시 언어에 따라 Lumetri 항목 이름이 다를 수 있습니다. 다이얼에 "항목을 찾지 못했습니다"라고 나오면 `deck.log`에 실제 항목 이름이 기록되니, 이슈로 알려 주세요.

## 프로그램별 자동 페이지 전환

PC에서 특정 프로그램이 앞에 오면 아이폰이 그 프로그램용 페이지로 바뀝니다. 기본으로 프리미어·애프터 이펙트가 다이얼·색보정 페이지에 연결되어 있습니다.
- **설정:** PC 편집 화면에서 페이지를 고르고, 왼쪽 **"이 페이지 자동으로 열기"**에 프로그램을 추가합니다. "최근 앞에 있던 프로그램"을 클릭하면 바로 들어갑니다.
- 한 프로그램을 여러 페이지에 연결하면, 그 페이지들 사이에서는 직접 고른 페이지가 유지됩니다.
- 끄려면 PC 편집 화면의 전체 설정에서 **프로그램별 자동 페이지 전환**을 해제합니다.

## 아이폰 하나로 여러 컴퓨터 조작

아이폰 화면 위쪽 가운데의 **이름을 누르면** 조작할 컴퓨터를 고르거나 추가할 수 있습니다. 다른 컴퓨터에서도 Phone Deck을 실행한 뒤, 그 컴퓨터의 QR 페이지에 나온 **주소**와 **접속 코드**를 입력하면 됩니다.

홈 화면 아이콘은 처음 추가한 컴퓨터의 주소로 열립니다. 그래서 그 컴퓨터가 꺼져 있으면 앱이 열리지 않으니, 주로 켜 두는 컴퓨터의 QR로 홈 화면 아이콘을 만드세요.

## 맥 (실험적)

같은 폴더로 맥에서도 실행할 수 있도록 맥용 도우미(`mac/helper.swift`), 맥 기본 설정(`config.mac.default.json`), 실행 파일(`*-mac.command`)이 들어 있습니다. 다만 Windows 버전만큼 확인하지는 않았습니다.

1. Node.js와 Xcode 개발 도구를 설치합니다. 터미널에서 `xcode-select --install`을 실행하면 됩니다.
2. 터미널에서 이 폴더로 이동해 `chmod +x *.command`를 실행한 뒤, `start-mac.command`를 엽니다. 첫 실행에는 도우미를 빌드하느라 1~2분 걸립니다.
3. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 터미널(자동 실행이면 node)을 허용합니다. 키 입력에 필요합니다.
4. 맥 주소는 `phonedeck-mac.local`입니다.

## 보안

- 버튼을 누르거나 바꾸는 모든 요청에는 **접속 코드**가 필요합니다.
- PC 편집 화면과 접속 코드를 보여 주는 QR 페이지는 **그 PC에서 `localhost`로 연 경우에만** 동작합니다.
- PC 브라우저로 연 다른 웹사이트가 몰래 버튼 동작을 바꾸거나 명령을 실행하지 못하게 막혀 있습니다.
- **명령어 실행(`run`) 버튼은 입력한 명령을 그대로 실행합니다.** 직접 이해하는 명령만 넣으세요.
- 연결은 같은 네트워크 안의 일반 HTTP입니다. 공용 Wi-Fi에서는 쓰지 않는 것을 권합니다.

## 설정 파일 직접 고치기 (고급)

내 설정은 `config.json`(맥은 `config.mac.json`)에 저장됩니다. 파일을 저장하면 아이폰 화면이 바로 바뀝니다. 처음 설정은 `config.default.json`에서 복사됩니다. 기본 설정으로 되돌리려면 `config.json`을 지우고 다시 실행하세요.

```json
{
  "columns": 4,
  "landscapeColumns": 6,
  "rows": 4,
  "pages": [
    { "name": "기본", "apps": ["Adobe Premiere Pro"], "buttons": [
      { "label": "캡처", "icon": "scan-line", "color": "#2bd46a", "action": { "type": "hotkey", "keys": "win+shift+s" } }
    ]}
  ]
}
```

| 전체 설정 | 설명 |
|---|---|
| `columns` / `landscapeColumns` | 세로 / 가로 화면의 열 수 |
| `rows` | 최소 줄 수 |
| `sound` | `false`면 다이얼 딸깍 소리를 끕니다 |
| `autoSwitch` | `false`면 프로그램별 자동 페이지 전환을 끕니다 |
| `hostName` | 고정 주소 이름 (기본 `phonedeck` → `phonedeck.local`) |

페이지에는 `apps`(자동 전환할 프로그램 이름)와 `lang: "en"`(다이얼 모드 표시를 영어로)을 넣을 수 있습니다. 빈칸이 필요하면 버튼 자리에 `{}`를 넣으세요.

### 버튼 아이콘

| 쓰는 법 | 결과 |
|---|---|
| `"icon": "play"` | 흰 선 아이콘. 이름은 [lucide.dev/icons](https://lucide.dev/icons)에서 찾습니다 |
| `"icon": "🎬"` | 이모지나 글자 |
| `"image": "auto"` | 버튼이 여는 프로그램의 실제 아이콘 (`open` 동작만) |
| `"image": "logo.png"` | `icons` 폴더에 넣은 이미지 |
| `"color": "#4a7dff"` | 버튼 테두리 색 |

### 동작 종류 (`action`)

| type | 예시 | 설명 |
|---|---|---|
| `hotkey` | `"keys": "ctrl+shift+t"` | 키 조합. 쉼표로 이어 쓰면 차례대로 누릅니다: `"ctrl+a, ctrl+c"` |
| `text` | `"text": "안녕하세요", "enter": true` | 글자 입력 (한글·이모지 가능) |
| `open` | `"target": "https://…"` 또는 `"notepad.exe"`, `"args": "…"` | 웹사이트·프로그램·폴더 열기. `%USERPROFILE%` 같은 환경 변수를 쓸 수 있습니다 |
| `run` | `"command": "PowerShell 명령"` | 숨겨진 창에서 명령 실행 |
| `multi` | `"steps": [ … ]`, `"gap": 60` | 여러 동작을 차례로 실행 |
| `delay` | `"ms": 300` | `multi` 안에서 잠시 기다림 |
| `page` | `"page": "매크로"` | 다른 페이지로 이동 |
| `volume` / `volmute` | `"delta": 5` | 볼륨 올리기·내리기 / 음소거 전환 |
| `lumetri` | `"key": "exposure", "delta": 0.1` | 프리미어 Lumetri 값 조절 (`"reset": true`면 기본값) |

### 다이얼 (`dial`)

다이얼은 기본 2×2칸이고, `"span": 1`이면 1칸짜리 작은 다이얼이 됩니다. 한 바퀴는 24칸(`ticksPerTurn`)이고, 가운데를 탭하면 `press` 동작을 실행합니다. 오른쪽 위 토글로 정밀/빠르게 모드를 바꿉니다.

| type | 설정 | 설명 |
|---|---|---|
| `volume` | `step`, `fastStep` | PC 볼륨 (% 단위). 탭하면 음소거 |
| `keys` | `left`, `right`, `fastLeft`, `fastRight` | 한 칸마다 단축키 한 번 (예: 타임라인 프레임 이동) |
| `wheel` | `step`, `fastStep`, `axis: "x"`, `hold` | 커서 위치에서 마우스 휠 굴리기 |
| `mouse` | `step`, `fastStep`, `axis: "y"`, `hold` | 커서 위치의 숫자 값을 마우스로 좌우로 끌기 |
| `lumetri` | `param`, `step`, `fastStep` | 프리미어 Lumetri 값 (`exposure` `contrast` `highlights` `shadows` `whites` `blacks` `temperature` `saturation`) |

### 키 이름

- 수정키: `ctrl` `shift` `alt` `win` (맥: `cmd` `option`)
- 일반 키: `a`–`z`, `0`–`9`, `f1`–`f24`, `enter`, `esc`, `tab`, `space`, `backspace`, `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`, `up`, `down`, `left`, `right`, `printscreen`, `hangul`, `hanja`
- 미디어 키: `playpause`, `next`, `prev`, `stop`, `mute`, `volup`, `voldown`
- 기호 키: `minus`, `equal`, `comma`, `period`, `slash`, `semicolon`, `quote`, `[`, `]`, `backslash`, `backtick`
- 숫자패드: `num0`–`num9`, `add`, `subtract`, `multiply`, `divide`

## 알아두면 좋은 점

- **관리자 권한으로 실행된 창**(작업 관리자, 일부 게임 등)에는 키 입력이 전달되지 않습니다. 필요하면 `start.bat`을 관리자 권한으로 실행하세요.
- `win+l`(화면 잠금)은 Windows가 막습니다. 기본 설정처럼 `rundll32.exe user32.dll,LockWorkStation`을 여는 방식을 쓰세요.
- 버튼이 없는 빈 곳을 좌우로 밀어도 페이지가 넘어갑니다.
- OBS를 조작하려면 OBS 설정에서 장면 전환 단축키를 지정하고, 같은 키로 `hotkey` 버튼을 만드세요.
