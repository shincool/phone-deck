공유 → PC로 보내기

유튜브·인스타·틱톡은 영상으로 받고,
다른 웹페이지는 PDF·문서로 저장해요.

① 이 주소를 복사해 두세요
…
주소가 phonedeck.local 로 시작하면 Wi-Fi든 핫스팟이든 바꿔도 그대로 쓸 수 있어요.
② 단축어 앱에서 만들기 (한 번만)
  1. 단축어 앱 → 오른쪽 위 ＋ → 이름을 PC로 보내기로 바꿔요. 단축어는 아이폰에 기본으로 들어 있는 앱이에요 (보라·분홍 네모 두 개가 겹친 아이콘). 안 보이면 홈 화면 가운데를 아래로 쓸어 단축어를 검색하고, 지웠다면 App Store에서 무료로 다시 받으면 돼요.
  2. 먼저 아래쪽 ⓘ(세부사항) → 공유 시트에서 보기를 켜고 완료를 눌러요. 이걸 먼저 해야 4번에서 쓸 단축어 입력(= 공유한 주소)이 생겨요. 화면 위에 '입력 받기'가 생기면, 입력이 없을 때 → 클립보드 가져오기로 해 두면 링크 복사 후 단축어만 눌러도 돼요.
  3. 아래 동작 검색에서 URL의 콘텐츠 가져오기를 추가해요. 파란 URL 글자를 눌러 ①에서 복사한 주소를 붙여넣어요.
  4. 그 동작 오른쪽의 ›를 눌러 펼친 뒤, 위에서부터: • 메서드: GET을 눌러 POST로 바꿔요.
    • 요청 본문: JSON 그대로 둬요.
    • 그 아래 ＋ 새로운 필드 추가를 누르고 목록에서 텍스트를 골라요.
    • 한 줄에 빈칸 두 개가 생겨요. 왼쪽 칸(키)에 영어 소문자로 url 이라고 써요.
    • 오른쪽 칸(텍스트)을 누르면 키보드 위에 회색 단추들이 떠요. 거기서 단축어 입력을 눌러요. (직접 글자를 쓰는 게 아니라 단추를 골라 넣는 거예요)     다 하면 url │ 단축어 입력 처럼 보이면 성공이에요. "공유한 주소를 url 이라는 이름표를 붙여 PC로 보낸다"는 뜻이에요.
  5. 알림 보기 동작을 추가하고, 내용 자리를 눌러 키보드 위 단추에서 URL의 콘텐츠를 골라요. PC가 보낸 "PC로 보냈어요 — 영상을 받을게요" 같은 답이 알림으로 떠요.
③ 써 보기
유튜브·인스타·사파리에서 공유 → PC로 보내기를 누르면 끝이에요. 받은 영상은 PC의 다운로드 폴더에 저장돼요. 통합 다운로더의 '채널백업에 바로 저장'이 켜져 있으면 채널백업 폴더로 들어가요. mp3로만 받고 싶으면 단축어를 하나 더 만들고 JSON에 mode = audio 필드를 추가하세요.
